# About SSMConnect

SSMConnect is a free, open-source app for Windows and Linux that connects you to AWS servers over Systems Manager (SSM) Session Manager with port 22 closed. It finds your servers, opens the tunnels, and sets up PuTTY, WinSCP, MobaXterm and Remote Desktop. Extra feature: copy files between two servers with two panes and a Copy button.

Start here: https://poonchezhian.github.io/docs/getting-started/ . Download: https://github.com/poonchezhian/ssmconnect/releases/latest/download/SSMConnect-Setup-x64.exe
