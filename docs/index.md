# SSMConnect documentation

- [Getting started with SSMConnect on Windows](https://poonchezhian.github.io/docs/getting-started/): Install SSMConnect on Windows, run the setup wizard, sign in to AWS and connect to your first server over Systems Manager with port 22 closed.
- [Copy files between servers](https://poonchezhian.github.io/docs/file-transfer/): Copy files and folders from one AWS server to another with two panes and a Copy button. Port 22 stays closed and the servers never need to reach each other.
- [Dashboard guide](https://poonchezhian.github.io/docs/dashboard-guide/): What every part of the SSMConnect dashboard means: server cards, status colours, CPU, memory and disk bars, Stop and Start connections, menus and the tray icon.
- [AWS accounts and organizations](https://poonchezhian.github.io/docs/aws-accounts-and-organizations/): Sign in once for a company IAM Identity Center sign-in and see every AWS account under it. Add, rename and remove accounts in SSMConnect.
- [Server types and tags](https://poonchezhian.github.io/docs/server-types-and-tags/): How SSMConnect decides that a server is PROD, UAT or development from its AWS tags, and how to tag instances so the labels are right.
- [Troubleshooting](https://poonchezhian.github.io/docs/troubleshooting/): Fixes for the most common SSMConnect problems: SSM ready No, PuTTY authentication errors, expired sign-in, Stopped cards, file transfer and Remote Desktop issues.
- [Frequently asked questions](https://poonchezhian.github.io/docs/faq/): Quick answers about SSMConnect: port 22, keys, supported tools, accounts, production use, updates and where to report a bug.
- [Security](https://poonchezhian.github.io/docs/security/): How SSMConnect keeps connections local, validates input, stores no secrets, protects converted keys and handles file transfer safely.
- [For IT teams](https://poonchezhian.github.io/docs/for-it-teams/): What servers and people need for SSMConnect: SSM Agent, instance roles, IAM permissions, pre-filled sign-in settings, tagging and unattended installs.
- [SSMConnect for Linux](https://poonchezhian.github.io/docs/linux-edition/): A native Linux app for connecting to AWS servers over SSM with port 22 closed: dashboard, Terminal, Files over SFTP, Remote Desktop and signed packages.
- [Install and update on Linux](https://poonchezhian.github.io/docs/linux-install-and-update/): Which SSMConnect file fits your Linux distribution, how to check the OpenPGP signature, install, update and remove.
- [Linux release notes](https://poonchezhian.github.io/docs/linux-release-notes/): What changed in each SSMConnect for Linux release.
- [What is new in SSMConnect for Windows](https://poonchezhian.github.io/docs/whats-new/): Release notes for every SSMConnect for Windows version, from the first file transfer window to the 2.0 dashboard.
