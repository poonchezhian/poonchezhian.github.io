SSMConnect documentation

Everything you need to connect to AWS servers over Systems Manager, copy files between them and keep it all working. New here? Start with Getting started, then try copying files between servers.

Get started

Getting started with SSMConnect on Windows

Install SSMConnect on Windows, run the setup wizard, sign in to AWS and connect to your first server over Systems Manager with port 22 closed.

Copy files between servers

Copy files and folders from one AWS server to another with two panes and a Copy button. Port 22 stays closed and the servers never need to reach each other.

Dashboard guide

What every part of the SSMConnect dashboard means: server cards, status colours, CPU, memory and disk bars, Stop and Start connections, menus and the tray icon.

Accounts and servers

AWS accounts and organizations

Sign in once for a company IAM Identity Center sign-in and see every AWS account under it. Add, rename and remove accounts in SSMConnect.

Server types and tags

How SSMConnect decides that a server is PROD, UAT or development from its AWS tags, and how to tag instances so the labels are right.

Troubleshooting

Frequently asked questions

Security

How SSMConnect keeps connections local, validates input, stores no secrets, protects converted keys and handles file transfer safely.

For IT teams

What servers and people need for SSMConnect: SSM Agent, instance roles, IAM permissions, pre-filled sign-in settings, tagging and unattended installs.
